## 评分规则
- 禁投行业剔除 + 财务硬筛
- 基本面分 = min(100, ROE × 3 + 净利润增长率 × 1.5)
- 风险分 = max(0, 50 + 年涨跌幅(%) − 最大回撤(%) × 1.5)
- 舆情分 = sentiment_score
- 总分 = round((基本面分 + 风险分 + 舆情分) / 3)
- 信号灯：总分 ≥ 75 → 🟢；60 ≤ 总分 < 75 → 🟡；< 60 → 🔴
- 估值偏高（PE > 60）：即使总分 ≥ 75 也降级为 🟡
