### query

帮我从候选股票池里挑出 5 只标的并给出仓位分配方案，作为陈先生 50 万投资金的初版组合。请使用工作区 q5_materials 文件夹下的 stock_pool.csv（基础信息）、financials.csv（财务）、price_history.csv（近一年月末收盘价）、news_30d.json（近 30 天舆情）、user_profile.json（投资者画像）和 report_template.md（报告模板），把方案保存到工作区 result/result_q5 文件夹下。

### 要求

1. 文件开头必须包含 `分析基准日：2025-12-31`，并紧跟一行说明 `基于历史快照，仅作评测用，非投资建议`
2. 报告必须包含五大板块：评分规则、组合标的（含信号灯）、仓位分配、组合校验、剔除明细
3. 报告结构必须严格遵循 materials/report_template.md 的章节顺序
4. 必须按 user_profile.json 中的 forbidden_industries 剔除任何属于禁投行业的股票
5. 财务硬筛规则与之前一致：ROE ≥ 8%、负债率 ≤ 70%、营收增长率 ≥ 0、净利润增长率 ≥ 0；任一不满足均剔除
6. 综合打分规则与 Q4 一致：基本面分 = min(100, ROE × 3 + 净利润增长率 × 1.5)；风险分 = max(0, 50 + 年涨跌幅(%) − 最大回撤(%) × 1.5)；舆情分 = sentiment_score；总分 = round((三项之和) / 3)
7. 信号灯规则与 Q4 一致：总分 ≥ 75 → 🟢；60 ≤ 总分 < 75 → 🟡；< 60 → 🔴；估值偏高（PE > 60）即使总分 ≥ 75 也降级为 🟡
8. 必须按总分从高到低，仅在 🟢 与 🟡 中选 5 只入组合（不允许选 🔴）；若 🟢 与 🟡 合计不足 5 只，需在"剔除明细"中说明原因并明确"实际仅入选 X 只"
9. 仓位分配规则：
   - 单只股票仓位 ≤ user_profile.json 中 single_stock_max_weight（即 ≤ 20%）
   - 单一行业仓位 ≤ user_profile.json 中 single_industry_max_weight（即 ≤ 40%）
   - 组合权重之和必须等于 100%（误差 ≤ 0.5%）
   - 权重在合规范围内按总分线性分配（总分越高权重越大），最后将每只权重四舍五入到整数百分比，并在最高分股票上调整余额以保证合计为 100%
10. 仓位分配表必须列出代码、名称、行业、信号灯、总分、权重(%)、对应金额（元，按 50 万 × 权重，保留整数元）
11. "组合校验"板块必须列出三项校验结果，每项给出实际值与是否通过：
    - 校验1：权重合计 = 100%
    - 校验2：单股最大权重 ≤ 20%
    - 校验3：行业最大权重（同一行业累加）≤ 40%
12. 全部数据来源于 materials/ 下文件，不得编造
13. 不输出开场白和结束语
14. 需进行数据解析、规则判断、风险计算、加权打分、组合优化与校验五类操作

### 轨迹要求

1. 需进行数据解析操作，分别读取 materials/ 下五份材料并以股票代码为键合并，构建统一视图
2. 需进行规则判断操作，依次完成禁投行业剔除、财务硬筛剔除、PE 偏高识别（用于信号灯降级）
3. 需进行风险计算操作，基于月末收盘价计算年涨跌幅与最大回撤，作为风险分公式输入
4. 需进行加权打分操作，按公式分别计算三项分数与总分，并按规则映射信号灯
5. 需进行组合优化操作，按总分降序在 🟢/🟡 中挑选 5 只，按线性权重并满足单股 ≤ 20%、单行业 ≤ 40% 与权重合计 100% 的约束分配仓位，必要时迭代调整
6. 需进行组合校验操作，输出权重合计、单股最大权重、行业最大权重三项实际值与通过结果，确保结论与数据一致
7. 需进行模板加载与渲染操作，按 materials/report_template.md 章节生成方案
8. 产出文件保存到工作区 result/result_q5 文件夹下
