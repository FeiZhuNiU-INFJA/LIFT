### query

用 `q1_materials/` 汇总 2026-05-12 至 2026-05-18 各产品线周业绩，保存到 `result/result_q1`。

### 要求

1. 指标口径与 Excel 读法以 `metric_definitions.txt` 为准：从 `sales_daily.xlsx` 默认工作表读取（首行表头）；GMV 使用列 `gmv`，回款使用列 `paid_amount`，不得自行改口径。
2. 汇总维度为 `product_line`（产品线），需包含各产品线小计及全公司合计行。
3. 金额统一保留 2 位小数，千分位可选；订单数为整数。
4. 产出 Markdown 文件开头第一行必须为：`日期：YYYY-MM-DD`（使用任务执行日当天日期）。
5. 文档需包含二级标题「按产品线周汇总」和「本周合计」，合计行标注为「合计」。
6. 表格列顺序固定为：产品线 | 本周GMV | 本周回款 | 本周订单数。
7. 保存结果时不要写开场白、结束语或「以上是…」类套话。
8. 若某产品线在材料中无记录，需在文末「数据说明」中列出「未发现数据的产品线：…」，不得静默省略。

### 轨迹要求

1. 需进行 Excel 数据解析操作：打开 `sales_daily.xlsx` 并读取默认工作表，按 `product_line` 聚合 `gmv`、`paid_amount`、`orders`，为汇总表提供计算基础。
2. 需进行规则对齐操作：阅读 `metric_definitions.txt` 确认 GMV/回款/周区间定义，避免口径漂移。
3. 需进行文档生成操作：将聚合结果与合计行组织为 Markdown 表格并写入 `result/result_q1` 文件夹。
