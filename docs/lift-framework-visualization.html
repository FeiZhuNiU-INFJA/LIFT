框架长什么样

用考试来理解：warmup 是练习题，hold-out 是期末考，delta 是进化后的记忆快照。

Suite
一张卷子

如 hello.json，多道题一起评

Warmup
练习题

触发进化，产物写入 delta 镜像

Hold-out
期末考

baseline vs evolved 严格对照

默认 最后一题 是 hold-out holdout_count 默认 1 成绩单 → report.json

CLI / Pipeline 切题、循环、写 report
↓
AgentRuntimeAdapter 容器、进化、chat 怎么调
↓
lift/eval 单题 work + judge 多轮（跟 OpenClaw 无关）

sequenceDiagram participant P as Pipeline participant A as Adapter participant W as Warmup 容器 participant H as Hold-out 容器 P->>A: warmup 题（如 Q1） A->>W: 起一个容器，连续做题 W->>W: evolve（learn review） W->>W: docker commit → delta 镜像 A->>W: 删掉 warmup 容器 loop 每道 hold-out 题（如 Q2） P->>A: baseline A->>H: 从 base 镜像起新容器 P->>A: evolved A->>H: 从 delta 镜像起新容器 end P->>P: 写 report.json
Warmup 共用一个容器

状态要连续，进化才有意义

Hold-out 每轮新容器

baseline 必须是干净环境，题间 workspace 隔离

多道 hold-out 共用 delta

只换 workspace，不重复进化

OpenClaw 接入做了哪些事

核心原则：宿主机编排，容器内执行。Python 不直接跑 OpenClaw CLI，而是 docker run + docker exec。

hello.json 端到端走一遍

最小冒烟集：Q1 练、Q2 考两遍。

Q1 · Warmup
「回复一下你好」

练习题 → evolve → commit

Q2 · Hold-out
「自我介绍一下你自己」

baseline（base 镜像）vs evolved（delta 镜像）

默认切分
holdout_count = 1

最后一题是 hold-out，前面都是 warmup

怎么跑

# 准备（首次）
bash agent-runtimes/openclaw/build-image.sh

# 冒烟：只 warmup + evolve
python -m src.cli.lift_main -r openclaw --suite hello.json --warmup-only

# 完整 LIFT
python -m src.cli.lift_main -r openclaw --suite hello.json --run_id hello-full

执行顺序

  1. 读卷 — Q1 → warmup，Q2 → hold-out
  2. Warmup — 一个容器跑 Q1，work + judge 多轮
  3. Evolve — openclaw learn review
  4. Commit — docker commit 得 delta，删 warmup 容器
  5. Q2 baseline — base 镜像 + seed workspace
  6. Q2 evolved — delta 镜像 + 同样 seed
  7. 落盘 — report.json + 默认后处理

跑完看哪里

flowchart TB R["results/{run_id}/"] R --> REP["report.json\nQ2 baseline / evolved 分数"] R --> OUT["outcome/run-0/"] OUT --> WU["warmup/Hello/\nQ1 + learn review"] OUT --> BL["baseline/Hello/Q2/"] OUT --> EV["evolved/Hello/Q2/"] R --> PP["*_comparison_metrics.csv\n*_metrics_report.html"]

EvalReport └── runs[0] └── suites[0] ← hello.json └── tasks[0] ← Q2（hold-out） ├── baseline: PhaseRun └── evolved: PhaseRun

Delta 镜像是临时中间产物，suite 跑完会被删掉。调试进化过程看 outcome/.../warmup/。

收尾

LIFT = warmup 进化 → 同一道 hold-out 题考两遍 → 看有没有 LIFT 框架 = Pipeline 编排 + eval 阅卷 + adapter 接 runtime OpenClaw = 4 个钩子 + 容器/chat/evolve/seed 胶水 hello.json = Q1 练 → Q2 对照 → report + outcome
