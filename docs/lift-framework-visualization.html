2. CLI 入口与常用参数

# 完整 LIFT（默认含后处理）
python -m src.cli.lift_main -r openclaw --suite hello.json --run_id hello

# 跳过后处理（调试 / Langfuse 未配置）
python -m src.cli.lift_main -r openclaw --suite hello.json --no-evaluate

# 仅后处理已有 report
python -m src.cli.lift_main -r openclaw --evaluate-only --run_id hello
参数默认含义
-r / --agent-runtime 必填 选择 Agent 运行时适配器（当前 openclaw → OpenClawAdapter）
-e / --evaluate / --no-evaluate on 评测结束后自动后处理（Langfuse backfill、CSV、HTML）；BooleanOptionalAction
--evaluate-only off 跳过 benchmark，仅对已有 report 跑 postprocess（需 --run_id）
--warmup-only off 只跑 warmup + evolve + delta，跳过 hold-out 对照
--repeat / --serial-repeats 1 / 并行 repeat 多轮 LIFT；默认 repeat 间并行
-p / --parallel off warmup 题并行（同一 warmup 容器内 asyncio.gather）

4. OpenClaw 接入：4 个特化点 + 支撑模块

OpenClaw 适配器本身约 85 行；容器生命周期与 delta commit 由 ContainerAgentRuntimeAdapter 通用层承担。

特化钩子实现位置做什么
resolve_docker_image openclaw/adapter.py 确定 base 镜像：优先 RunOptions.docker_image 覆盖，否则读 container_defaults.yaml（evolve-eval-openclaw:latest）
start_container openclaw/session.py docker run 启动 gateway 容器；挂载 workspace、.env、benchmarks；可选 workspace seed 同步
worker_judger_factory openclaw/chat_agent.py 绑定 env 后返回 OpenClawWorkerJudgerPairFactory（callable）；factory(task) 时在容器内 docker exec openclaw 创建 work/judge
apply_evolve openclaw/evolve.py warmup 结束后调用 self-evolving-plugin-pro 的 learn review（worker.js）

通用 Container 层（OpenClaw 继承，无需重复实现）

模块职责
container/session.py参数化 docker run、ContainerSession 生命周期、chown 清理
container/volumes.py宿主机路径解析、task / default 卷挂载
container/delta.pydocker commit 生成 delta 镜像
container/adapter.pywarmup/holdout 环境启动、baseline 镜像、delta 物化
openclaw/container_exec.py容器内异步执行 openclaw CLI
openclaw/workspace_seed.py镜像内 /opt/evolve-eval/workspace_seed → 工作区

6. Eval 内核（运行时无关）

flowchart LR subgraph Adapter F[WorkerJudgerPairFactory] F -->|__call__ task| P[WorkerJudgerPair] end subgraph Eval EP[execute_task] RT[run_task] P --> EP EP --> RT end subgraph Agents W[work_agent.chat] J[judge_agent.chat] end RT --> W W --> J J -->|JSON score| PR[PhaseRun]

run_task 是唯一的 work+judge 多轮循环；Adapter 只负责提供 WorkerJudgerPairFactory（绑定容器 / session），不感知 LIFT 对照语义。 is_evolve_turn / is_final_task 通过 CustomTags 写入 Langfuse，供后处理区分 baseline/evolved。
