Evolution-Impact Leaderboard

How much does each agent runtime actually improve on unseen tasks after warmup + one evolve step? Every runtime is run twice per holdout task — a clean Base and an evolved Loaded image — and we rank the difference. This is not a raw-capability leaderboard: each row differences out its own Base, so the ranking never compares raw ability across runtimes.

How to read this. The ranking key is ΔTurns% = (Σ evolved − Σ baseline) / Σ baseline × 100 over paired holdout task-repeats. All four efficiency deltas (Turns / Tools / Tokens / Latency) are lower-is-better: a negative value means the evolved agent did the same tasks with fewer turns/tokens — that is the good direction. A positive value means it got less efficient. Sig. ✓ marks runtimes whose 95% CI on ΔTurns% (over 10 repeats, population std) lies entirely below zero — the only rows with a repeat-stable signal.
