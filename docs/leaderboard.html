01 01 / THE SIGNAL

The interval is the result.

The ranking key is ΔTurns% = (Σ evolved − Σ baseline) / Σ baseline × 100 over paired holdout task-repeats. All four efficiency deltas (Turns / Tools / Tokens / Latency) are lower-is-better: a negative value means the evolved agent did the same tasks with fewer turns, the good direction; a positive value means it got less efficient.

Sig. ✓ marks runtimes whose 95% CI on ΔTurns% (10 repeats, population std) lies entirely below zero; n.s. rows still straddle zero. The green band identifies only the ✓ cluster — the runtimes whose interval stays entirely on the improvement side of zero.

ΔTurns% with 95% confidence interval

Each runtime shows its point estimate (dot) and 95% CI (whiskers) over 10 repeats. A whisker clearing the zero line entirely is a repeat-stable gain; one crossing zero is statistical noise. Class badge: D per-task distillation · C carry-only · R post-hoc reflection.

◄ negative = fewer turns = better positive ► = more cost = worse point estimate 95% CI (10 repeats) CI crosses 0 = noise repeat-stable band (CI fully below 0)
